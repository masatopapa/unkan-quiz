# 運行管理者（貨物）4択問題集

運行管理者試験（貨物）の過去問（令和2年度第1回・第2回、令和2〜6年度CBT出題例）216問から10問をランダム出題し、1問ごとに正解と解説を表示して100点満点で採点するブラウザ問題集です。スマホのホーム画面に追加するとアプリのように使えます（PWA）。

公開URL: https://masatopapa.github.io/unkan-quiz/

- 問題は公益財団法人運行管理者試験センターが公表した過去問題・出題例をもとに4択形式に組み替えています。
- 解説はAIが現行法（2026年時点）に合わせて書き起こしたものです。数値・条文は最新の法令で確認してください。
- 更新はネット優先のService Workerで自動配信されます（次に開いたときに新版になります）。
